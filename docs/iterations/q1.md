# Q1: independent relative speech-quality evidence

Prior design: [RFC #17](https://github.com/zengchuang-hw/qwen3-tts-cpp-a2/issues/17),
including the balanced-window and 444-new-token amendments recorded before
quality scoring or accepted generation. This iteration changes the harness only.

The fixed 128-text C005 comparison passed seven concurrency cohorts against
upstream b4451682abac651f26046f8d27467de3f007e1e7. The additional C007 corpus
exposed an intermittent nonzero native shutdown and eight inexact C16 outputs.
That failed run stays failed. Similar waveforms and later clean exits do not
establish quality equivalence or a lifecycle fix.

Q1 uses pinned multilingual Whisper-small and WavLM-base-plus-sv on CPU float32.
Model cards: [Whisper](https://huggingface.co/openai/whisper-small),
[WavLM speaker model](https://huggingface.co/microsoft/wavlm-base-plus-sv).
Revisions, Git blobs and complete asset sizes are in `data/q1-models.json`.
The asset definition itself is fixed in the verifier. All bytes are verified
before generation and again before/after scoring. Public weights can be
downloaded elsewhere and transferred; audio is evaluated locally.

```bash
python speech_quality.py freeze --models-root /work/quality-models \
  --native-build /work/q1/build --reference-root /work/reference --model /model \
  --workload /work/c007/source/data/heldout-32.jsonl --output /work/q1/freeze.json
python speech_quality.py generate --freeze /work/q1/freeze.json \
  --boundary /work/q1/generation.json --run /work/q1/generated \
  --concurrencies 4 16 --requests 32 --repetitions 1
python speech_quality.py score --freeze /work/q1/freeze.json \
  --boundary /work/q1/generation.json --run /work/q1/generated \
  --output /work/q1/scores
```

Run inside the dedicated A2 container with its established CANN environment,
physical card 3 selected and checked idle, offline model loading, and source/build
on `PYTHONPATH`. `freeze` verifies the clean upstream checkout, candidate source
and binaries, TTS assets/runtime, evaluator assets/packages and workload.
`generate` creates an immutable boundary before a new campaign directory, records
its real exit separately, and leaves the campaign's existing server ownership and
readiness/benchmark/60-second shutdown bounds intact. Old recordings cannot be
promoted through a new freeze. The boundary is an audit record on the same host,
not a cryptographic attestation against a malicious operator.

Every WAV is audited against retained request evidence and real lifecycle exits.
Exact PCM follows the existing equivalence route. In an inexact cohort, all
reference utterances receive real ASR; exact candidate pairs reuse only their
identical PCM's result. Other candidates receive independent ASR and speaker
inference. No predicted score is taken from user JSON. Transcript edit errors and
speaker cosines are recomputed from actual tokens, transcripts and embeddings.

Audio is resampled 24k to 16k using the frozen polyphase filter. Balanced contiguous
windows cover every sample, at most 30 seconds for ASR and 6 seconds for speaker.
Greedy en/zh transcription uses a verified four-token prefix and at most 444 new
tokens (448 total decoder positions); hitting that limit is inconclusive even
with EOS. Speaker windows are normalized individually, weighted by real duration,
then the aggregate is normalized. Short clips use masked padding after actual
sample normalization; insufficient feature context is inconclusive.

WER/CER increase must be at most one percentage point independently per language,
concurrency and repetition. Each inexact speaker pair must have cosine >= .98
against its paired reference. This measures relative content/speaker preservation
under these particular evaluators; it does not establish subjective naturalness,
absolute speaker identity, production stability or speed. Missing or invalid
evidence is INCONCLUSIVE; observed failures remain FAIL. A quality-tooling merge
does not accept an inexact runtime or waive the pending C007/C008 gates.

Rejected alternatives: subjective waveform similarity cannot substitute for ASR;
external audio APIs reduce reproducibility; choosing evaluators after observing
quality would bias acceptance; fixed-length cuts leave very short tail windows;
averaging languages/cohorts can hide regressions. Dependencies load lazily so the
control modules and CPU contract tests remain importable without torch/NPU.

Validation evidence belongs under `evidence/q1-speech-quality/`. Actual A2 scoring,
negative controls, exits, locks and limitations are required before this PR can
merge. This document does not claim those checks have run.
