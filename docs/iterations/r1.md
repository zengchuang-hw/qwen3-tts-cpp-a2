# R1: pinned InferRSI TTS adapter

Prior [RFC #14](https://github.com/zengchuang-hw/qwen3-tts-cpp-a2/issues/14).
Uses InferRSI bd5e356ac9267362c80f27adba61d76e047583c7 through its RunSpec and
harness.runner APIs, with truthful repo_type=qwen3_tts_cpp. The CLI enum does not
provide this target. The adapter verifies clean exact SDK Git and import paths;
its control imports/help do not require torch/NPU or the SDK to be installed.

rsi.py has run/trial/validate CLI subcommands. run --dry-run prints a plan only;
actual runs need the prepared Linux Ascend environment and one selected device.
Use --inferrsi-root, --reference-root, --candidate-root, --native-build, --model,
--workload and --output-root; select the qualified engine options explicitly.
Default full coverage is sevenC,128 requests,3 pairs, primary C64. A smoke can
use --concurrencies 4 --requests 4 --repetitions 1 --primary-concurrency 4.
Outputs/build must be outside clean Git source checkouts; JSON is evidence only.

InferRSI owns AB/BA, Git snapshots, deadlines and its generic report. TTS trial
outputs are unique per trial, and actual directory mappings feed the unchanged
TTS math/gates without copying or aliasing audio. campaign.trial accepts optional
supervision; rsi uses SDK launch_server/stop_server so server/children stay inside
the trial group. Hard runner SIGKILL cannot leave a detached serving session.
Standalone campaign keeps its previous default ownership behavior.

The generic report covers its declared primary throughput only. validation
exit0 establishes the supplied actual PCM/completeness checks, while tts-final.json
keeps the authoritative sevenC strict min/max/p95/PCM result. A short exact-audio
smoke remains whole-target INCONCLUSIVE, preserving any raw short-cohort FAIL
and the primary verdict beside it. Missing quality/source/trials cannot PASS.
A generic primary PASS cannot override TTS FAIL/INCONCLUSIVE or missing coverage.

C001-C005 remain experiments executed by the original campaign.py. Replaying
immutable evidence checks assessor compatibility, not new NPU performance or
retroactive InferRSI execution. New actual runner run IDs, process groups, real
exits, source/environment and waveform artifacts must be retained separately.
