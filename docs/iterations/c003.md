# C003: reproducible optimized control and high-batch diagnosis

Design: [RFC #6](https://github.com/zengchuang-hw/qwen3-tts-cpp-a2/issues/6),
recorded before the delivery PR. This replaces the delivery path of historical
PR #2, without merging it or rewriting its design-order gap.

The runtime adapters, paired rotary option, input bound and runtime identity
guards are restored from `0bf15b257298cfd0e07e36220204480d9910d09e`.
The default rotary remains `native`. Historical C002's all-concurrency result
remains FAIL; adopting an opt-in research control does not meet the speed goal.

`profile_native.py` now accepts `--slots` and `--profile-index`. Repeating a
frozen long input makes steady high-batch diagnosis possible; the report records
input indices, workload hash and active requests at every measured step.
Such synthetic repeated-input traces are diagnostic, never the serving workload.
Profiler warnings and incomplete output must be retained. Summed kernel time
is not a critical-path or end-to-end throughput measurement.

Required A2 checks: fresh new-path Release build, compiled ownership tests,
rotary parity, actual complete reference/native WAV comparison including
cancellation/reuse, a four-request native executable run and a B64 trace with
verified active population. CPU suite and syntax checks also apply.

The former physical card 2 is occupied by a separate workload. This iteration
selects an idle healthy 910B3 card after checking actual device visibility. Both
arms of future timed comparisons must be remeasured on that same card; results
cannot be compared across cards as an optimization gain.

Validation results are recorded below. No new performance PASS is asserted. Evidence belongs in
`evidence/c003-control-profile/{plan,results,patch,validator}`; large WAVs/traces
remain in the isolated remote workspace with manifests and retrieval paths.
The next optimization will have its own prior RFC and PR.

Code inspection identifies a next hypothesis: the native runtime accumulates
audio events until all due codec groups finish, whereas the reference emits
within each group. An incremental callback may reduce high-concurrency TTFA;
it must be designed and tested separately without assuming a throughput gain.
Paired rotary tiling is another measured diagnostic target (37.78 ms across
1,200 calls); its achievable benefit requires a separate operator microbenchmark.
